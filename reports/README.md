# Reports

This directory keeps lightweight artifacts that make the public demo reproducible:

| File | Meaning |
|---|---|
| `all_training_results.json` | Multi-model comparison/ensemble experiment record. |
| `ensemble_results.json` | Ensemble result summary. |
| `optimization_results.json` | Hyperparameter-optimization result summary. |
| `enhanced_training_results.json` | Enhanced-feature/simulation experiment summary. |
| `figures_4charts/*.png` | Example figures used by the technical narrative. |

The high-R² enhanced result is retained as an experiment record only. It is not a claim of verified production generalization.
Generated PDFs/DOCX files and trained model binaries are intentionally excluded from the public release.
