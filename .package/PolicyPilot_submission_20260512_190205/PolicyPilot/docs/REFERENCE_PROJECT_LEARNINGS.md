# 参考项目吸收记录

## 参考项目

- 项目：opcgate / OPC 选址决策工具
- 仓库：https://github.com/siuserxiaowei/opc-policy
- License：MIT
- 本地路径：`reference_repos/opc-policy`
- 提交建议：`reference_repos/` 已加入 `.gitignore`，只作为本地研究资料；正式提交时使用本项目已吸收的导入器、字段设计和界面能力。

## 已吸收能力

1. 结构化政策字段

   本项目 `Policy` 模型已扩展政策层级、发文单位、状态、发布日期、申报窗口、申报方式、官方链接、更新时间、核验状态、最高金额和补贴明细等字段。

2. OPC 政策库导入

   `src/policy_loader.py` 新增 `load_opc_policies()`，可读取 `reference_repos/opc-policy/data/policies.json`，并转换为本项目政策匹配所需格式。

3. 区域匹配增强

   `src/matcher.py` 增加省市包含关系，省级政策可以匹配省内城市，例如广东政策可匹配广州、深圳、东莞等城市。

4. 前端展示增强

   Streamlit 侧边栏新增“OPC 一人公司政策库（本地参考）”，政策详情页展示发文单位、政策层级/状态、申报窗口、最高金额、官方原文链接和核验状态。

5. 城市对比与数据质量检查

   `src/policy_insights.py` 新增城市政策汇总、申报窗口倒计时和政策库质量检查。前端可按区域对比政策数量、官方来源、核验数量、最高金额、最近窗口，并列出缺少来源、材料清单、发文单位或申报窗口的政策数据问题。

## 未直接照搬的部分

- 未替换成本项目的前端整站，因为对方是静态政策导航和城市对比工具，本项目核心仍是企业画像抽取、申报准备度评分、材料缺口识别和申报书初稿生成。
- 未将第三方政策数据混入 `data/public_policies.json`，而是保留来源目录和导入函数，便于标注来源、复核授权和后续更新。
- 未使用对方的营销内容、二维码、个人联系方式等与本项目无关的素材。

## 后续可继续吸收

- 政策更新机制：增加 changelog/RSS 或“最近核验时间”提醒。
- 数据校验脚本：按 schema 检查政策库字段是否缺失、链接是否有效。
