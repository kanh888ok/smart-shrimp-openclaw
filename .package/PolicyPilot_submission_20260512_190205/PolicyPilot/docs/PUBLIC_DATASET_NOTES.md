# PolicyPilot 公开来源数据说明

## 结论

本包新增的是“公开来源 + 脱敏 outcome 标签”的数据，不是政府内部审批数据。

可以真实表达为：

> 当前版本接入官方公开政策文本和公开公示/公告结果，构造脱敏的政策申报初筛数据集。系统评估的是申报准备度和材料风险，不直接预测官方最终审批通过率。

不能表达为：

> 我们拿到了政府内部审批数据。
> 我们可以准确预测是否通过官方审批。

## 新增文件

```text
data/public_policies.json
  官方公开政策文本结构化摘要。可被系统直接加载用于匹配。

data/public_source_catalog.csv
  数据来源目录。每条包含来源类型、URL、用途和真实性等级。

data/public_outcome_cases_desensitized.csv
  公开公示/公告结果构造的脱敏 outcome 样例。只保留 case_id、policy_id、region、case_group、outcome_label 等字段。

data/desensitization_rules.json
  脱敏规则和标签定义。
```

## 可扩充数据源

后续可继续从官方公开公示和公告中扩展脱敏 outcome 样例。候选来源清单见：

```text
data/public_expansion_source_candidates.csv
docs/DATASET_EXPANSION_AND_DESENSITIZATION.md
```

这些候选源包括 AI 算力券/人工智能券资格审核公示、科技型中小企业拟入库/入库公告、专精特新中小企业公示/公告等。扩充时仍只保留 `case_id`、`policy_id`、地区、批次、公示阶段、标签和来源 URL，不保留企业实名、统一社会信用代码、联系方式、合同金额、申报书原文或专家评分。

## 真实性分级

| 数据 | 真实性 | 说明 |
|---|---|---|
| public_policies.json | 真实公开政策的结构化摘要 | 条件来自官方政策/通知，但不是原文全文；为避免版权和冗余，已做摘要化 |
| public_source_catalog.csv | 真实来源目录 | URL 指向官方或公开网页/PDF |
| public_outcome_cases_desensitized.csv | 公开公示结果派生的脱敏样例 | 不含企业实名，不含统一社会信用代码，不含联系人，不含完整申报材料 |
| sample_policies.json | 模拟数据 | 保留用于没有网络素材时演示，不应称为真实数据 |

## 为什么没有完整“脱敏审批数据集”

公开网页通常只披露政策文本、申报通知、公示名单、入库公告，很少披露每家企业的完整申报书、财务数据、合同、专家评分、退回原因。后者属于商业秘密或敏感业务数据，通常需要企业授权、主管部门授权或园区合作后才能获得。

因此，本项目的数据路线是：

```text
官方政策文本 → 结构化政策库
公开公示/公告 → 脱敏 outcome 标签
企业自填/授权材料 → 企业画像与材料状态
专家标注 → 评分校准
```

## 对外说明措辞

建议说：

> 第一版 MVP 使用公开政策文本和公开公示结果构建数据基线。我们对公示名单进行了脱敏处理，只保留地区、政策、主体类型和 outcome 标签，不保留企业实名和敏感材料。当前评分是“申报准备度评分”，用于初筛和材料风险提示。后续若与园区或服务机构合作，可接入授权后的历史申报材料和退回原因，对评分阈值进行真实校准。

## 求职项目表述

可写：

> 基于官方公开政策文本和公开公示公告，构建政策申报 RAG 知识库与脱敏 outcome 样例集；设计数据脱敏策略，移除企业实名、统一社会信用代码、联系方式、合同金额等敏感字段，仅保留 case_id、政策ID、地区、主体类型与公示结果标签，用于政策匹配和申报准备度评分的离线校准。
