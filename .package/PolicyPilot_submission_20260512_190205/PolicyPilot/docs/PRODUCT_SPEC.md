# PolicyPilot 产品构思

## 1. 行业痛点

中小企业和创业团队在政策申报中常见问题：

1. 政策条款分散，企业不知道自己能申报什么；
2. 申报条件复杂，企业难以判断是否满足资格；
3. 材料准备靠人工经验，缺口发现太晚；
4. 申报书可写，但风险与证据不足难以提前发现；
5. 园区企业服务人员重复答疑，初筛成本高。

## 2. 目标用户

- 中小企业、科技初创公司；
- 园区企业服务中心；
- 创业孵化器；
- 财税/政策咨询机构；
- 政企数字化服务商。

## 3. 产品定位

PolicyPilot 是政策申报前置决策系统，不是单纯文案生成器。

核心输出：

- 可申报政策排行；
- 匹配分与评分拆解；
- 命中理由与引用依据；
- 材料清单与缺口；
- 风险等级与补救动作；
- 申报书初稿。

## 4. MVP 范围

第一版只做：

1. 企业简介输入；
2. 政策库加载；
3. 企业画像抽取；
4. 政策匹配评分；
5. 材料状态判断；
6. 风险提示；
7. 申报书/产品介绍/报告导出。

不做：

- 真实政务接口；
- 用户登录；
- 付款系统；
- OCR；
- 大规模向量库。

## 5. 成功标准

现场演示 3 分钟内完成闭环：

```text
输入企业材料 → 点击分析 → 出政策排行 → 点开风险 → 生成申报书 → 下载报告
```
