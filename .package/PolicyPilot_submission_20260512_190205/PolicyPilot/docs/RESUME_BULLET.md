# 简历写法

## 中文版本

**PolicyPilot 企业政策申报与材料生成 AI Agent**

- 构建面向园区企业和中小企业的政策匹配与申报材料生成系统，支持企业画像抽取、政策条款检索、资格匹配评分、材料清单生成、风险提示与申报书初稿生成。
- 设计区域、产业、资格、材料完备度、证据强度五维评分体系，并基于缺失材料和高风险项进行扣分，输出可解释的政策匹配结果。
- 实现轻量 RAG 检索模块，从政策库中抽取相关要求、材料和风险条款，作为生成内容的引用依据，降低大模型幻觉风险。
- 使用 Streamlit 搭建交互式前端，支持政策 PDF/TXT 上传、结构化结果展示、Markdown/JSON/CSV 报告导出。
- 项目可应用于政企数字化、园区企业服务、创业孵化器和中小企业服务 SaaS 场景。

## 英文版本

**PolicyPilot: AI Agent for Policy Grant Matching and Application Drafting**

- Built an AI-assisted policy application system for SMEs and industrial parks, covering company profile extraction, policy clause retrieval, eligibility scoring, material checklist generation, risk analysis, and application draft generation.
- Designed a five-dimensional scoring framework covering region, industry, qualification, material readiness, and evidence strength, with explainable deductions for missing documents and high-risk items.
- Implemented a lightweight RAG-style retrieval module to cite relevant policy clauses and reduce hallucination in generated application materials.
- Developed an interactive Streamlit dashboard supporting policy PDF/TXT uploads, structured analysis display, and Markdown/JSON/CSV exports.
- Positioned the system for government-enterprise digitalization, industrial park services, incubators, and SME SaaS scenarios.
