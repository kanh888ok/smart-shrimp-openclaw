# 评审维度对应

## 创新性

PolicyPilot 将政策申报从“文案生成”提升为“申报前置决策系统”，把企业画像、政策条款、材料状态、风险等级和申报书生成整合成闭环。

## 技术可行性

MVP 使用稳定技术栈：

- Python；
- Streamlit；
- Pydantic/Dataclass 风格结构化模型；
- PDF/TXT 政策解析；
- 轻量条款检索；
- 规则评分；
- 可选 LLM 生成。

即使没有 API Key，也能完整演示。

## 商业价值

目标客户明确：

- 园区企业服务中心；
- 创业孵化器；
- 中小企业；
- 财税/政策咨询机构；
- 政企数字化服务商。

可按项目制、SaaS 订阅、咨询工具授权等方式商业化。

## 现场表现

演示链路短：输入企业 → 分析 → 排行 → 风险 → 初稿 → 导出。

用户和合作方容易理解，也能体现 AI 工程能力和行业落地能力。
