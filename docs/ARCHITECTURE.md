# PolicyPilot 技术架构

## 1. 架构图

```text
企业输入 / 上传材料
        ↓
企业画像抽取 company_parser
        ↓
政策库加载 policy_loader
        ↓
政策条款切片 retriever
        ↓
规则评分 matcher
        ↓
材料状态 / 风险等级 / 下一步动作
        ↓
生成器 generator
        ↓
Streamlit 展示 + Markdown/JSON/CSV 导出
```

## 2. 核心模块

### company_parser.py

从自然语言中抽取：

- 企业名称；
- 地区；
- 行业；
- 成立年份；
- 团队规模；
- 年营收；
- 研发投入占比；
- 知识产权；
- Demo/试点；
- 合同/合作证明；
- 预算说明。

### retriever.py

轻量政策条款检索，基于 token + ngram + TF-IDF 思路，无外部依赖。用于输出“引用依据”，降低生成幻觉。

### matcher.py

评分维度：

| 维度 | 权重 |
|---|---:|
| 区域匹配 | 25 |
| 产业匹配 | 25 |
| 企业资格 | 20 |
| 材料完备度 | 15 |
| 证据强度 | 15 |

并根据材料缺口和高风险项扣分。

### generator.py

生成：

- 申报书初稿；
- 材料清单；
- 60 秒产品介绍；
- 常见问题；
- Demo 说明。

默认使用模板，避免现场演示时外部 API 不稳定。可选 OpenAI 改写申报书。

## 3. 可扩展方向

- 接入 OCR：营业执照、财报、软著证书；
- 接入向量数据库：FAISS/Chroma/Milvus；
- 接入真实政策库定时更新；
- 接入园区后台：企业列表、政策热度、高风险材料；
- 接入在线申报接口或 RPA。
