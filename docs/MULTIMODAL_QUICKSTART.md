## 🔧 常见问题

### Q1: 训练时显示"数据不足"？

**A**: 数据量太少（<20天）。建议：
- 生成更多示例数据
- 使用更小的滑动窗口
- 选择晚期融合（更鲁棒）

### Q2: 早期融合和晚期融合选哪个？

**A**:
- **数据完整** → 早期融合（快）
- **有缺失值** → 晚期融合（稳）
- **不确定** → 先试早期，再试晚期

### Q3: 混合融合报错"PyTorch未安装"？

**A**: 安装PyTorch或跳过混合融合
```bash
pip install torch
```

或使用早期/晚期融合即可。

### Q4: 如何添加真实图像数据？

**A**: 修改代码中的图像特征提取器
```python
# 在 multi_modal_fusion.py 中
image_extractor = ImageFeatureExtractor(method='cnn')
```

### Q5: 特征重要性全是0？

**A**:
- 检查数据是否有问题
- 增加训练数据量
- 使用晚期融合
