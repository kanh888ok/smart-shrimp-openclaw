# 数据来源与指标口径

## 数据层

本项目不是完整真实虾塘数据集，而是“真实生物测量数据 + 行业成本参数 + 仿真养殖过程”的组合原型。

| 数据 | 位置 | 用途 | 口径 |
|---|---|---|---|
| Kaggle 虾体测量数据 | `data/kaggle_shrimp_with_treatment.csv` | 重量、长度、体积等生物学基准 | 真实测量数据 |
| 30 天养殖样例 | `data/shrimp_farming_sample.xlsx` | Web 演示、报告生成、规则决策 | 样例/仿真数据 |
| 成本参数 | `data/cost_data_from_paper.py`、`src/roi_calculator.py` | ROI、成本收益分析 | 行业资料整理 |
| 实验结果 | `reports/*.json` | 模型对比和训练结果 | 实验结果记录 |

## 指标解释

项目材料中出现多个 R²，是因为它们来自不同实验设置：

| 指标来源 | 含义 | 解释 |
|---|---|---|
| README 历史稿中的 R²≈0.44 | 基线模型 | 保守基线，反映早期特征集/设置 |
| `reports/all_training_results.json` | 多模型对比/集成实验 | 用于展示模型融合效果 |
| `reports/enhanced_training_results.json` | 增强特征/仿真场景实验 | 不能直接解释为真实生产泛化性能 |
| 技术报告中的表格 | 竞赛提交叙事 | 应结合实验设置解读 |

公开仓库统一表述为：**本项目展示可运行的智能养殖分析与决策流程，性能指标仅代表相应实验设置下的结果。**

## ROI 解释

ROI 计算模块基于行业成本区间、养殖模式参数和固定假设生成理论测算。它适合用于方案比较和演示，不应被直接视为实际投资收益承诺。
