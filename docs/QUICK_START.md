## ❓ 常见问题

**Q: 训练时间太长？**
A: 减少epochs或使用更少的模型

**Q: GPU不可用？**
A: 深度学习会自动使用CPU，只是稍慢

**Q: 内存不足？**
A: 减小batch_size或使用采样数据

**Q: 某个模型无法使用？**
A: 检查是否安装了对应的依赖包
