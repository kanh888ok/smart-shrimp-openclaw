# 智虾系统技术架构图

## 方案1：使用Python生成（推荐）

运行以下命令生成高清架构图：

```bash
cd 源代码
python scripts/generate_architecture_diagram.py
```

生成3个PNG图片：
- `reports/technical_architecture_diagram.png` - 技术架构图
- `reports/data_flow_diagram.png` - 数据流图
- `reports/opencraw_interaction_diagram.png` - OpenClaw交互图

## 技术栈详细说明

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| **用户层** | Streamlit | Web界面 |
| | Flutter | 移动APP |
| | REST API | 接口服务 |
| **执行层** | Python | 业务逻辑 |
| | Celery | 异步任务 |
| | Redis | 缓存队列 |
| **决策层** | OpenClaw | AI智能体 |
| | 对话驱动 | 自然语言交互 |
| **分析层** | Scikit-learn | 机器学习 |
| | XGBoost | 梯度提升 |
| | PyTorch | 深度学习 |
| | Prophet | 时序预测 |
| | SHAP | 可解释性 |
| **数据层** | Pandas | 数据处理 |
| | NumPy | 数值计算 |
| | MySQL | 关系数据库 |
| | TimescaleDB | 时序数据库 |
| **感知层** | MQTT | 物联网协议 |
| | ESP32 | 传感器节点 |
| | Modbus | 工业协议 |
