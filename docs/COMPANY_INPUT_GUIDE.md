# 企业输入格式说明

## 1. 输入方式

企业用户不需要上传完整申报书，也不需要按严格 JSON 填写。第一版支持自然语言输入，用户可以直接粘贴企业简介、项目介绍或材料清单。

推荐输入内容包括：

```text
企业名称：
注册地区：
所属行业：
成立时间：
团队规模：
上一年度营收：
资产总额：
科技人员人数或占比：
研发投入占比：
知识产权情况：
产品/项目简介：
当前进展：
客户/合同/订单/合作证明：
已准备材料：
缺失或尚未准备的材料：
希望申请的政策方向：
```

## 2. 必填与选填

建议至少填写：

- 注册地区
- 所属行业
- 团队规模
- 营收或经营阶段
- 资产总额
- 科技人员或研发人员占比
- 研发投入或研发团队情况
- 知识产权/技术成果情况
- Demo、试点、部署或客户案例
- 已准备和缺失的申报材料

可选填写：

- 具体政策名称或补贴方向
- 合同、订单、合作证明的简要描述
- 预算、费用计划、算力使用计划
- 是否有财务报表、纳税证明、真实性承诺书
- 是否存在重大违法、失信、安全、质量或环保风险记录

## 3. 示例

```text
杭州云策智能科技公司是一家 AI 初创公司，注册在杭州，团队 8 人，主营大模型客服与企业知识库问答系统。
公司成立于 2024 年，年营收 80 万元，研发投入占比 35%，已有 1 项软件著作权，暂无发明专利。
产品已经完成 Demo，并在园区企业客服场景完成试点部署。
目前希望申请算力补贴、科技型中小企业认定和创新创业资金。
企业已准备项目计划书，但尚未准备算力合同、正式财务报表和预算说明。
```

## 4. 不建议输入的信息

演示版不需要用户输入以下敏感信息：

- 统一社会信用代码完整号码
- 法人或联系人身份证号
- 电话、邮箱、详细地址
- 银行账户
- 完整合同文本
- 完整财务报表原文
- 未公开的商业秘密

如需表达证据状态，可以写成：

```text
已有算力服务合同，但暂不上传原文。
已有 2024 年财务报表，可后续补充。
已有客户试点证明，当前仅提供摘要。
```

## 5. 系统会抽取什么

系统会从输入中抽取企业画像：

- 地区
- 行业
- 成立年份
- 团队人数
- 年营收
- 资产总额
- 研发投入占比
- 科技/研发人员占比
- 知识产权
- Demo/试点/部署
- 财务材料
- 合同/订单/合作证明
- 预算说明
- 关键词

抽取结果会用于政策匹配、评分拆解、材料缺口识别和风险提示。

## 6. 知名企业兜底识别

系统内置了 `data/known_enterprises.json` 作为知名企业基础画像兜底表。当前覆盖 98 个常见国内大厂及 162 个别名；企业材料中出现阿里巴巴、腾讯、华为、字节跳动、百度、京东、美团、小米、宁德时代、比亚迪、顺丰、中芯国际、小红书、OPPO、vivo、京东方、长江存储、深信服等名称时，系统会优先使用兜底表校正地区、行业和企业标签，减少把“客户所在行业”误判成“企业自身行业”的情况。

这个表只存企业名称别名、地区、行业和企业类型标签，不存联系人、统一社会信用代码、财务明细或未公开材料。
