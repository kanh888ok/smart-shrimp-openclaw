PolicyPilot

企业政策申报与材料生成 AI Agent

面向企业服务机构、园区和中小企业的政策申报准备度诊断系统。基于企业材料抽取画像，匹配公开政策条款，识别材料缺口与申报风险，并生成申报书初稿和可解释分析报告。
产品形态 Streamlit 交互式应用
核心能力 画像抽取、政策匹配、材料生成
适用对象 园区、企服机构、中小企业

1. 背景与痛点

企业在申报政策时通常面临三个现实问题：政策分散、条件复杂、材料准备不透明。政策文件散落在不同主管部门网站，企业难以判断自己适合申报哪些方向；同一政策又包含注册地、行业、企业规模、研发投入、知识产权、财务材料、信用记录等多项条件，需要反复人工核对。

对园区和企业服务机构而言，日常咨询量高、重复问题多，人工初筛成本高。企业经常只问“我能申报什么政策”，但服务人员需要先还原企业画像、判断资格边界、梳理材料缺口，再给出下一步建议。

企业侧 不清楚应该提供哪些信息，也不知道材料缺什么、风险在哪里。
服务侧 需要重复解读政策、核对资格、整理材料清单，效率低且难标准化。
政策侧 条款分散在通知、指南、公示和附件中，缺少结构化检索和条件匹配。
决策侧 只生成申报书不够，关键是先判断是否值得申报、如何补齐证据。

2. 解决方案

PolicyPilot 将政策申报前置环节拆成可解释的流程：企业输入自然语言材料后，系统先抽取企业画像，再从政策库中匹配候选政策，输出评分拆解、材料状态、风险提示和下一步动作，最后生成申报书初稿、材料清单和完整分析报告。

3. 功能亮点

自然语言输入 企业无需填写复杂 JSON，可直接粘贴企业简介、项目材料或材料清单。
标准填写模板 系统提供建议字段，帮助企业知道应该补充哪些关键数据。
中小企业边界识别 结合职工人数、销售收入、资产总额、信用记录等指标判断是否适合中小企业类政策。
知名企业兜底画像 内置常见国内大厂基础画像，减少行业、地区和企业属性误判。
政策库洞察 展示政策数量、区域覆盖、官方来源、核验状态、城市对比和最高金额。
申报窗口倒计时 支持截止日期、固定窗口和周期性窗口，提示进行中、即将截止或常态化。
数据质量检查 自动标记缺少官方来源、申报条件、材料清单、发文单位或申报窗口的政策数据。
报告导出 支持 Markdown、JSON 和 CSV 导出，便于后续整理、复核和归档。

4. 技术架构

系统采用轻量、可解释、可本地运行的架构。核心匹配和材料判断不依赖外部模型，默认可离线运行；如配置 API Key，可进一步对申报书初稿进行语言润色。

5. 数据来源与安全边界

第一版数据以公开政策文本、公开公示摘要、脱敏 outcome 样例和模拟演示数据为主。系统不保存企业真实敏感材料，不要求输入统一社会信用代码完整号码、联系人身份证号、电话、银行账户、完整合同或完整财务报表原文。

数据类型 用途 安全处理
公开政策摘要 政策匹配、条款引用、材料要求 保留来源链接与结构化字段
脱敏 outcome 样例 展示结果标签和评分校准思路 去除企业实名、联系方式和敏感财务数据
知名企业基础画像 校正常见大厂地区、行业和企业属性 仅保存名称别名、地区、行业和标签
企业输入材料 实时分析企业画像与材料缺口 演示版本地处理，不要求上传敏感原文
系统定位为申报前置诊断与材料准备辅助，不直接预测官方审批结果。正式申报前仍需结合最新政策原文、主管部门要求和人工复核。

6. 使用流程

  1. 选择政策库：公开来源政策库、模拟演示政策库或用户上传政策文件。
  2. 粘贴企业简介或使用标准填写模板补充企业数据。
  3. 点击开始分析，系统自动抽取企业画像并生成政策匹配排行。
  4. 查看单条政策的评分拆解、命中理由、材料状态、风险提示和引用依据。
  5. 下载申报书初稿、材料清单、完整分析报告和政策匹配 CSV。

企业推荐填写字段

企业名称、注册地区、成立时间
职工总数、销售收入、资产总额
行业方向、科技人员与研发费用
知识产权、软著、专利、技术成果
Demo、试点、部署、客户案例
合同、订单、预算、财务材料

7. 创新点与落地价值

创新点

  • 从“写申报书”前移到“申报准备度诊断”，先判断能不能报、缺什么、风险在哪。
  • 将企业画像、政策条件、材料证据和风险提示统一到一条可解释链路中。
  • 同时支持中小企业边界识别和知名大厂基础画像校正，减少规模和行业误判。
  • 把政策库质量纳入产品界面，展示来源覆盖、核验状态、区域分布和申报窗口。

落地价值

对象 价值
中小企业 快速知道适合关注哪些政策、缺少哪些材料、是否存在明显申报风险。
园区/孵化器 降低重复咨询成本，形成标准化企业政策初筛流程。
企业服务机构 提升政策咨询、材料辅导和客户初筛效率。
政策运营团队 通过数据质量检查发现政策库缺项，推动政策数据持续维护。

8. 后续规划

  • 接入更多真实政策来源，建立定期更新、人工核验和版本记录机制。
  • 支持营业执照、财报、合同、软著、专利证书等材料的 OCR 与结构化抽取。
  • 增加企业材料证据链，做到每个评分点都能引用政策原文和企业材料片段。
  • 引入人工复核工作台，支持修改画像、调整材料状态和生成复核记录。
  • 完善权限、脱敏、日志和数据隔离，面向真实企业服务场景部署。
PolicyPilot 的目标不是替代人工审核，而是把政策申报前的大量重复判断、材料梳理和风险初筛自动化，让企业和服务机构更早发现问题、更快补齐证据。
