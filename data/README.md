# Data

This directory contains only sample/demo data used by the public repository.

| File | Purpose | Interpretation |
|---|---|---|
| `kaggle_shrimp_with_treatment.csv` | Shrimp body measurement baseline | Public sample retained from the competition package. Check the original dataset license before commercial redistribution. |
| `shrimp_farming_sample.xlsx` | 30-day farming scenario | Simulated/demo data for UI, report, and decision-flow testing. |
| `cost_data_from_paper.py` | Cost and ROI parameters | Literature-derived parameters used for scenario analysis. |
| `kaggle_shrimp_data_processor.py` | Data preprocessing example | Script for processing body-measurement data. |
| `real_data_integrator.py` | External-data integration example | Weather/sensor integration scaffold; no real API key is included. |

The sample workbook is not a real pond production log. Model and ROI outputs should be treated as experiment/simulation results.
